# 🛠️ Pisos Epóxicos Toluca

Sitio web responsivo y optimizado para un negocio local de aplicación de pisos epóxicos. Diseñado para mostrar proyectos reales paso a paso, facilitando la conversión de clientes mediante contacto directo a WhatsApp.

## 🚀 Enlace en Vivo
Puedes ver el sitio desplegado y funcionando aquí: 
👉 [Pisos Epóxicos Toluca](https://manudevmx.github.io/pisos-epoxicos-toluca/)

## ✨ Características Principales
* **Diseño Responsivo:** Adaptado de forma fluida para dispositivos móviles y computadoras.
* **Galerías Especializadas:** Secciones organizadas por tipo de acabado (Autonivelante, Mortero, Hojuela, Mormoleado y Antiderrapante).
* **Visor de Imágenes:** Experiencia visual optimizada para detallar la calidad de los trabajos.
* **Optimización de Conversión:** Integración de llamadas a la acción y chat directo por WhatsApp.
* **SEO Local:** Estructura preparada con metadatos y `sitemap.xml` para motores de búsqueda.

## 💻 Tecnologías Utilizadas
* **HTML5** / **CSS3**
* **JavaScript** (Manejo de lógica y animaciones de scroll)
* **CSS** (Preprocesador de HTML para plantillas limpias)
* **GitHub Pages** (Despliegue y hosting continuo)

## 📂 Estructura del Repositorio
- `Autonivelante/` - Trabajos y fotos de acabados autonivelantes.
- `Mortero/` - Sección de pisos de mortero epóxico.
- `Acabado_epoxico_hojuela/` - Galería de acabados con hojuela decorativa.
- `Acabado_Mormoleado/` - Muestra de estilos mormoleados.
- `Antiderrapante_con_zoclo_sanitario/` - Soluciones industriales y comerciales.
- `javascript/` - Scripts de animación e interactividad.
- `pug, CSS/` - Plantillas base del desarrollo.
